# Python To-Do List Application

## Project Description
The Python To-Do List Application is a simple command-line project that helps users manage their daily tasks efficiently.

Users can add new tasks, view their task list, and remove completed or unnecessary tasks.

The application also supports saving tasks in a text file so that tasks remain available even after closing the program.

## Features
- Add new tasks.
- View all tasks with serial numbers.
- Remove tasks by entering their task number.
- Save tasks automatically in a text file.
- Load previously saved tasks.
- Handle invalid user inputs.

## Technologies Used
- Python
- Visual Studio Code
- File Handling
- Lists and Functions

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Execute:

```bash
python todo_list.py
```
